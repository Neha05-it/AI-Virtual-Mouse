# AI-Virtual-Mouse
## Overview
AI Virtual Mouse is a Python-based computer vision project that allows users to control the mouse cursor using hand gestures instead of a physical mouse. It uses a webcam to detect hand landmarks in real time and converts different finger movements into mouse actions.
## Features
- Control mouse cursor using hand movements
- Left click using finger gesture
- Right click using finger gesture (if implemented)
- Drag and drop support (if implemented)
- Real-time hand tracking with webcam
- Smooth and responsive cursor movements
## Technologies Used 
- Python
- openCV
- MediaPipe
- PyAutoGUI
- NumPy

## How It Works
1. Open the application.
2. Allow webcam access.
3. Show your hand in front of the camera
4. Move your index finger to control the cursor.
5. Perform the required finger gesture to click or perform other action
